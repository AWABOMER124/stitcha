# التوصيل بالمدينة والحي

الإحداثيات اختيارية في طلبات APP_V1. يلزم اكتمال المدينة والحي والعنوان
التفصيلي، وربط المتجر بالشريك واعتماد الشريك وتغطية العنوان.

عند غياب موقع الاستلام أو التسليم، يطابق العرض المدينة والحي مع منطقة
الشركة ويستخدم تسعيرًا ثابتًا فقط. لا تُحسب رسوم كيلومتر أو قيود أقصى مسافة
بمسافة مخمّنة. تخزن المسافة غير المعروفة NULL، ولا تُستبدل بصفر.

يمكن حفظ منطقة خدمة بالمدينة والحي دون مركز أو دائرة تغطية. عند إدخال بيانات
الخريطة تُدخل كلها معًا، وتبقى قيود الدائرة فعالة عندما يتوفر موقع التسليم.
يعاد التحقق من التغطية والسعر والعزل عند قبول العرض.

تحمل sender.location وrecipient.location القيمة null في APP_V1 عند عدم
توفر الإحداثيات. تبقى بيانات العنوان وحقول الدفع وهوية التثبيت والتوقيع كما هي.
ناقلو LEGACY_HTTP يحتفظون بعقد الإحداثيات السابق.

تُطبق migration 20261116173000_optional_delivery_coordinates لتسمح بقيمة
NULL في delivery_quotes.distanceKm دون تعديل العروض الموجودة.

التحقق المحلي: 26 اختبار TypeScript للمطابقة والتسعير والقبول والإرسال،
وفحص أنواع للحسابات، واختبار مستقبل قياد لقبول الموقع null دون تخمين GPS.
لا تعني هذه الاختبارات وحدها نجاح البناء أو النشر أو إنشاء شحنة في الإنتاج.
