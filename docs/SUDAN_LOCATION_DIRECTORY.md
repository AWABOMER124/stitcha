## حدود الدليل المهمة

هذا **دليل أسماء أولي غير شامل**، وليس سجلاً حكومياً معتمداً أو خريطة حدود إدارية أو حصر كل قرى وضواحي السودان. لم تُخمّن إحداثيات أو تبعيات بين الأحياء الصغيرة والأحياء الأكبر. الأسماء المحلية والامتدادات قابلة للمراجعة مع شركة التوصيل الأولى.

وجود اسم في الدليل لا يعني توفر الخدمة أو سلامة الطريق أو فتح المنطقة للتوصيل. لم تُنشأ مناطق أو أسعار في حسابات الشركاء تلقائياً، ولم تتغير عروض التوصيل الحالية.

لا يلزم تحميل الدليل من الإنترنت عند استخدام البورتال، ولا توجد خدمة خرائط مدفوعة أو مفتاح خارجي مطلوب لهذه الإضافة.

## التشغيل

1. دخول الشريك إلى «التغطية والأسعار».
2. اختيار الولاية والمدينة ثم الحي، أو إدخال نطاق مخصص إذا لم يكن مدرجاً.
3. تحديد كود فريد داخل شركة التوصيل، وإحداثيات المركز ونصف القطر الحقيقي وزمن التوصيل.
4. حفظ المنطقة، ثم إضافة قاعدة التسعير المرتبطة بها.
5. اختبار طلب داخل التغطية وطلب خارجها قبل إتاحة الشركة للتجار، مع استكمال اعتماد ونشر تطبيق الشريك وربط التاجر.

**نصف القطر دائرة تشغيلية يحددها الشريك، وليس حدود الحي الرسمية.** اختيار اسم حي لا يكفي لقبول عنوان العميل، ولا يؤدي إلى تعبئة إحداثيات افتراضية قد تمنح تغطية خاطئة.

## التوافق والنشر

- لا تغيير في قاعدة البيانات ولا migration جديد لهذه الحزمة.
- حفظ `city` و`name` بالأسماء العربية المعتمدة للمدينة والحي؛ النطاقات اليدوية تُحفظ بالأسماء المدخلة بعد التحقق من الطول.
- معرّفات الدليل تُستخدم لاختيار القيم والتحقق منها، وليست حقولاً جديدة محفوظة في جدول التغطية. التقارير المبنية على معرّفات الولايات كأعمدة مستقلة تحتاج تغييراً لاحقاً في نموذج البيانات.
- تظل النماذج القديمة بلا حقول الدليل مقبولة مع التحقق من النصوص. لا تحويل أو إعادة تسمية للسجلات الموجودة.
- الربط الفعلي في هذه الحزمة يخص بورتال شريك التوصيل. الدليل قابل لإعادة الاستخدام؛ لم تُغير نماذج عناوين العملاء أو الفروع أو عقود API الخارجية.
- بعد دفع الحزمة إلى `main` يلزم نشر إصدار جديد في Dokploy. الدفع إلى GitHub وحده ليس إثباتاً للنشر على السيرفر.

## التحقق

اختبارات الوحدة تغطي تفرد المعرفات، وجود المدن في الولايات الـ18، قوائم المدن الست، مسح الاختيارات التابعة، رفض التبعية غير الصحيحة، استخراج الأسماء الصحيحة، والإدخال اليدوي والتوافق مع النماذج القديمة.

فحص البورتال المحلي يستخدم PostgreSQL معزولاً وخادم التطبيق الحقيقي، ويضيف حالات `C05–C08` للحفظ الفعلي، رفض التبعية الخاطئة دون كتابة، النطاق المخصص، ومنع إنشاء منطقة من اسم الحي فقط دون إحداثيات.

نتائج الفحص التفصيلية في `merchant-os/audit/partner-sudan-directory-results.json`. لا يتضمن هذا الاختبار أي طلب إنتاجي أو شريك حقيقي.
