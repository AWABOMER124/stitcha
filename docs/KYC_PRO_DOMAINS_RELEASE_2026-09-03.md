# إطلاق حدود Basic وKYC والنطاقات المخصصة

تاريخ التنفيذ: 3 سبتمبر 2026

## ما تم تنفيذه

- باقة Basic تسمح بحد أقصى 20 منتجاً نشطاً وفرع واحد وحساب فريق واحد. المنع مطبق في الخادم وبقفل تزامن عند الإنشاء أو إعادة التفعيل، وليس في الواجهة فقط.
- رصيد الذكاء الاصطناعي وربط واتساب والتصدير والنطاق المخصص معطلة في Basic وتتاح حسب صلاحيات باقة Pro.
- برنامج إحالة التجار يحتسب افتراضياً 20% من كل دفعة Pro مؤكدة لمدة 12 شهراً، ولا يمنح عمولة لمجرد إنشاء حساب مجاني.
- التاجر يرفع بطاقة هوية أو جوازاً سارياً من `/dashboard/verification` ويضيف وسيلة صرف العمولة.
- مسوّق المتجر يستلم رابط إعداد خاصاً صالحاً لسبعة أيام لإرسال هويته وبيانات السداد. الرابط أحادي الاستخدام بعد الإرسال.
- الإدارة تراجع هويات التجار والمسوقين من `/admin/verifications`. لا يمكن صرف عمولة قبل اعتماد هوية سارية ووجود وسيلة سداد.
- تاجر Pro يطلب نطاقه من `/dashboard/domains`، يثبت التحكم بسجل TXT، ثم تفعله الإدارة بعد ضبط Dokploy وSSL من `/admin/domains`.

## حماية البيانات

- صور الهوية تحفظ عبر طبقة التخزين الخاص، ولا توضع في مجلد الصور العامة.
- أرقام الهوية والحساب وIBAN تشفر بواسطة `SECRETS_ENCRYPTION_KEY`.
- تنزيل الوثائق يمر عبر مسار مصادق عليه مع `Cache-Control: private, no-store`.
- لا تعرض لوحة الإدارة الرقم الكامل للحساب؛ تعرض نسخة مقنعة فقط.

## إعداد الإنتاج المطلوب

1. خذ نسخة احتياطية قابلة للاسترجاع من PostgreSQL ومن وحدة التخزين الخاصة.
2. ثبّت `SECRETS_ENCRYPTION_KEY` ولا تغيّره بعد حفظ بيانات مشفرة.
3. استخدم `PRIVATE_S3_BUCKET` خاصاً، أو ثبّت الحجم الدائم `/app/storage/private` بصلاحية كتابة المستخدم `1001`.
4. اضبط `CUSTOM_DOMAIN_CNAME_TARGET=domains.wassla-sd.shop` وأنشئ له DNS يشير إلى خادم Dokploy.
5. نفّذ `prisma migrate deploy` قبل تشغيل صورة التطبيق الجديدة.
6. لكل نطاق تم التحقق منه: أضفه إلى التطبيق في Dokploy، انتظر إصدار SSL، اختبر HTTPS، ثم فعّله من لوحة الإدارة.

## اختبار القبول

- حساب Basic يستطيع نشر 20 منتجاً نشطاً ويرفض المنتج النشط رقم 21 برسالة مفهومة.
- نفس الحساب لا يستطيع استدعاء API للذكاء الاصطناعي أو التصدير أو واتساب عبر تجاوز الواجهة.
- حساب Pro يستطيع استخدام الميزات المدفوعة وربط نطاق بعد تحقق TXT.
- لا يستطيع مستخدم من متجر آخر تنزيل وثيقة KYC.
- لا يمكن اعتماد وثيقة منتهية، ولا صرف عمولة لمسوق أو تاجر غير موثق.
- أول دفعة Pro مؤكدة تنشئ عمولة واحدة فقط، وتكرار webhook أو المراجعة لا يكررها.
- انتهاء فترة سماح Pro يعيد المتجر لقيود Basic ويوقف توجيه النطاق المخصص آلياً.

## ملاحظة تشغيلية

المنصة تتحقق من ملكية النطاق، لكنها لا تعدّل Dokploy تلقائياً. الإضافة إلى Traefik وإصدار SSL خطوة إدارية يدوية حالياً حتى نبني تكاملاً آمناً مع API الاستضافة. لا ينبغي تفعيل النطاق من لوحة وصلة قبل نجاح HTTPS فعلياً.
